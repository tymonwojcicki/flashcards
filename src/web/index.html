Flashcards: instructions for AI assistants

This is Flashcards, a spaced-repetition app. When a user asks you to make flashcards for it, reply with one CSV code block:

  • First row exactly: front,back,deck,tags. Then one card per row. Comma-separated.
  • Quote a field with double quotes if it contains a comma, a double quote or a line break; write a double quote inside it as "".
  • front = question (short, one fact per card). back = answer. deck = path with :: for sub-decks, e.g. Biology::Cells (optional). tags = single words separated by spaces, hyphens inside a tag (optional).
  • Math: LaTeX between dollar signs, inline $x^2$ or block $$\frac{a}{b}$$, no space just inside the dollar signs.
  • Allowed HTML: b, i, u, br, ul, ol, li, sub, sup. No images or links. No comments inside the CSV.

Example row: What does the law of demand state?,"As price rises, quantity demanded falls.",Economics::Micro,demand

The user imports it via Decks, Import, then pastes the text or drops a .csv file.
